Avant de commencer

Trois choses à vérifier, sinon les élèves ne pourront pas rejoindre votre campagne.

  • Vous avez un accès à Pix Orga. L'invitation est envoyée sur votre adresse académique (prenom.nom@ac-nancy-metz.fr) par l'administrateur Pix Orga du collège, le référent numérique. Rien reçu ? Demandez-la en un clic : Demander mon accès par mail
  • Les élèves sont importés dans Pix Orga. C'est fait par l'administrateur depuis la base SIECLE en début d'année. Vous les voyez dans l'onglet « Élèves ».
  • Les élèves se sont connectés une première fois à Pix via le Médiacentre de MBN. Cette première connexion relie leur compte à leur fiche élève.

Calendrier 2026-2027 au collège

  1. Septembre, jusqu'au 17 octobre 2026 Parcours de rentrée 5e, 4e, 3e, avant les vacances d'automne. Déjà en place
  2. Toute l'année Parcours par domaine (SVT, Maths, Français, Techno…), dans votre discipline. À vous de les créer : c'est l'objet de ce tutoriel
  3. Toute l'année, en 4e Parcours IA obligatoires. Pris en charge par le référent numérique
  4. Du 15 mars au 11 juin 2027 Certification Pix des élèves de 3e.

Se connecter et lancer la création

Rendez-vous sur orga.pix.fr et connectez-vous avec votre adresse académique et votre mot de passe Pix Orga. Sur la page d'accueil, cliquez sur « Nouvelle campagne ».

Pas de mot de passe, ou oublié ?

Sur la page de connexion, cliquez sur « Mot de passe oublié » et saisissez votre adresse académique : vous recevez un lien pour en choisir un. C'est aussi le chemin à suivre si vous n'en avez jamais créé.

Se repérer dans les noms

  • [CLG] = parcours pour le collège. Ignorez les [LGT] et [LP].
  • Parcours de rentrée 5e / 4e / 3e : ceux à lancer en début d'année, en vie de classe ou dans votre discipline.
  • Disciplinaires : un parcours par matière (SVT, Maths, Français…), pratique pour votre cours.

À quoi servent ces deux options ?
  • Envoi multiple : si Oui, l'élève peut refaire le parcours et renvoyer ses résultats. Pratique pour un parcours d'entraînement, inutile pour une évaluation.
  • Identifiant complémentaire : demande une information de votre choix à l'élève au début (par exemple sa classe). Inutile au collège, les élèves importés sont déjà rattachés à leur classe.

Donner le code aux élèves

Écrivez le code au tableau ou envoyez-le par la messagerie MBN. Voici ce que font les élèves.

Via MBN recommandé

  1. Se connecter à MBN (Mon Bureau Numérique).
  2. Ouvrir le Médiacentre et cliquer sur Pix. La connexion à Pix est automatique.
  3. Cliquer sur « J'ai un code ».
  4. Saisir le code, puis « C'est parti ! ».

Via pix.fr

  1. Aller sur pix.fr et cliquer sur « J'ai un code ».
  2. Saisir le code.
  3. Se connecter avec ses identifiants Pix (créés lors de la première connexion via MBN).

Si un élève ne voit pas Pix dans le Médiacentre

La ressource ne lui a pas été affectée (fréquent pour un élève arrivé en cours d'année). Signalez-le au référent numérique.

Une campagne pour plusieurs classes

Inutile de créer une campagne par classe : donnez le même code à vos 4 classes de 4e et filtrez par classe dans « Activité ».

C'est tout !

En résumé, créer une campagne Pix, c'est :

  1. orga.pix.fr → Nouvelle campagne
  2. Objectif : Évaluer les participants
  3. Catalogue → choisir un parcours [CLG] → Sélectionner
  4. Nom de la campagne → Créer la campagne
  5. Donner le code aux élèves (MBN → Médiacentre → Pix → J'ai un code)
  6. Suivre dans Activité et Résultats
